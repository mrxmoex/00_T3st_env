# Seed schema

Canonical seed lives in TypeScript (`src/data/**`) so every food is type-checked against `src/types/catalog.ts`.

JSON snapshots (regenerated by `npx tsx scripts/export-seed.ts`):

- `sources.json` — ordered source catalog (USDA, FAO, EFSA, DGE, NIH, peer-reviewed, residue)
- `invariants.json` — seven biochemical invariants with source ids
- `categories.json` — eleven unequal ontology classes
- `foods.json` — raw seed foods before scoring
- `evaluated.json` — foods after completeness / bioavailability multipliers

Do not average plant categories. Scores are computed in `src/lib/scoring.ts` at load time.
